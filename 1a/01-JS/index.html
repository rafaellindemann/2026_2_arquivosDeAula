VS Code

Vamos apresentar aqui algumas coisas interessantes sobre esse editor de texto.

Atalhos de teclado

  • Alt + 'Z' :: quebra de linha (word wrap)
  • Ctrl + ',' :: abre configurações
  • Ctrl + '+' :: Zoom in
  • Ctrl + '-' :: Zoom out
  • Alt + setas cima/baixo :: move a linha ou seleção
  • Shift + mover cursor (setinhas/home/end/page down...) :: vai selecionando...
  • Alt + shift + setas cima/baixo :: replicar linha/seleção
  • Ctrl + ' ' :: abre o munu de sugestões
  • Ctrl + aspa :: mostra/esconde terminal
