{#0081} Exercícios simples para treinar leitura de input - beecrowd
1- Beecrowd 2374 - Pneu
Um input para pressão desejada; Um input para pressão lida.
2- Beecrowd 1759 - Ho Ho Ho Ho
Um input para o número de “Ho”s
3- Neps 86 - Aprovado ou Reprovado
Um input para cada uma das duas notas
4- Neps 13 - O bondinho
Um input para o número de alunos e um input para o número de professores
5- Beecrowd 1142 - PUM
Um input para ler a quantidade de PUMs que serão gerados
6- Beecrowd 1134 - Tipos de combustível
Alterando o escopo para somatório de quantidades, onde temos um input para cada tipo de combustível e um botão ao lado do input para “vender” aquela quantidade. O sistema mostra o total vendido de cada combustível.
Sugestão de layout ​
7- Beecrowd 1789 - A corrida de lesmas
Classificando uma lesma de cada vez. Digita a velocidade no input e aperta o botão pra classificar ela.
8- Beecrowd 1963 - O filme da Vovó
O trajeto Pomar agora em sua versão com Iputs para entrada das frutas e renderização condicional para gerar o recibo somente com as frutas que foram compradas!
